# Coursebook：新用户引导、页眉页脚清洗与正文编辑

## 功能方案

### 新用户引导

首次进入空白课程库时展示可跳过的四步教程：了解读/查/问/记 → 配置模型 → 导入与复核 → 阅读与编辑。已有课程的用户不强制弹出。侧栏常驻「使用教程」入口，可随时重看。

配置步骤解释 API 地址、模型名称、API Key 三者的关系；明确默认模式中解析使用 OCR 模型，翻译与助手使用文本模型，不能互相误用。复用真实配置页和连接测试，不另存密钥；连接测试由用户主动发起，并提示可能消耗额度。保存设置后回到教程下一步。跳过教程不限制功能。进度保存在本地工作区，不发送云端。

### 页眉页脚清洗

阅读器新增「页面清洗」。以同一文件内的位置、重复频率及页码变化检测候选，至少在三页出现；页码或带学校/版权等明显标识的边缘短文本才列为建议。图表文字、公式、表格、长段落、重复定义不自动处理。没有可靠位置信息时宁可不建议。

用户预览候选文本、来源页码，逐组勾选后隐藏。正文、检索及 Markdown 导出排除已隐藏项；原始文本、截图、contentId 与修正记录保留，页面角落可展开查看，原有定位仍有效。支持恢复；操作不调用模型，也不会删除原文件。既有课程可直接清洗，无须重新识别。清洗状态随课程导出，并在继续编译/重新识别后按相同 ID 和原文检查恢复，避免误套到变化后的内容。

### 手动修改正文

正文单元新增直接编辑按钮，页级入口和顶部「编辑正文」默认查看全部正文，可搜索原文/译文定位。复用左右对照原页的编辑器，支持段落、标题、列表、表格单元和公式。提供「保存」与「保存并下一项」，保留未保存离开保护和快捷键。

允许只修正原文：新原文立即生效，旧译文保留在历史中，显示待更新，避免将错误配对当作完成。用户可手填新译文或主动生成译文草稿，确认后保存。若译文确实无须变化，可明确勾选确认。稳定 ID 保持笔记与书签关联，高亮按现有重定位机制处理；搜索、正文、导出同步更新。保存检查版本冲突，编译进行中禁止修改。

## 验收

- 首次引导、跳过、重开、刷新持久化；配置入口和保存后的返回流程；教程不产生隐式模型调用。
- 带递增页码的重复页脚可检测；定义、引用、表格和无位置文本不得误清洗；隐藏/恢复/导出/重解析状态保留。
- 未译内容也能编辑；只改原文令译文待更新；确认相同译文、生成草稿、公式修改、历史与并发冲突。
- 使用隔离测试课程验证真实 HTTP 接口、浏览器交互与离线导出，运行现有回归。

功能开发验收完成后，经用户明确授权，纳入 Coursebook 2.2.0 发行。

## 使用入口

1. 课程库左侧「使用教程」：可重新打开引导；第二步直接进入真实的模型设置页。配置保存成功后返回教程第三步。
2. 阅读器顶部「页面清洗」：预览候选原文、文件和页码，勾选后隐藏；同一窗口可恢复选中项或全部隐藏项。页面底部的「已隐藏页眉页脚」保留可展开的记录。
3. 阅读器顶部「编辑正文」、页角「编辑」或段落旁 ✎：搜索并选择内容，对照原页修改，保存后立即更新正文。输入框下方可查看原始识别文本与修正历史。

清洗目前只建议同一文件中覆盖至少 60% 页面、且至少出现三页的可靠候选；不同文件不合并计算。位置信息缺失、与正文混在一个文本块的页尾、没有页码或机构/版权标识的短句不会自动列入建议。此类内容可先通过正文编辑纠正分块中的文本。本轮不加入模型辅助删除，避免额外费用和误删课程信息。
