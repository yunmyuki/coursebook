# 2.2.1 解析精度改进

默认保留“本地 PP-DocLayoutV3 版面分析 + 按需云端区域 OCR”。

- 从保留的源 PDF 直接渲染区域 PNG，避免从低清整页预览二次裁剪。区域字高决定倍率，同时限制边长、像素总量和倍率；缺少源文件时明确记录预览图回退。
- 按字体、行距、缩进、栏间空隙和分隔线重建段落；中文跨行不增加多余空格；保留原始行及坐标，不推测缺字或删除连字符。
- 可靠 PDF 线框表格复用原始文字与物理单元格边界；PPTX 使用实际列宽、行高、合并跨度，保留空格。扫描或不可靠网格继续区域 OCR。
- 区分精确与估算坐标、版面置信度与未知的文字置信度，记录区域渲染方法和原生表格复用计数。
- 兼容已完成课程缓存，不因升级自动重新识别；用户可选择重新识别单页，必要 OCR 和翻译仍按其服务计费。

新增精度回归覆盖多栏、段落、中文、合并单元格、空格、数字、旋转与 CropBox、源文件缺失、扫描重叠和缓存升级。`tools/benchmark_parser_precision.py` 可执行无付费请求的本地诊断；它不提供未经标注的 OCR 准确率分数。

这些改动不能保证任意复杂讲义零错误。原页、历史文字和人工复核继续保留；未加入未经基准验证的本地 OCR 引擎、跨页自动合并或图中文字删除策略。
