# 快速开始

## 安装与首次启动

1. 从 [GitHub Releases](https://github.com/yunmyuki/coursebook/releases/tag/v2.0.0) 下载 Windows x64 完整版或轻量版。
2. 用 Windows 自带解压功能解压整个 ZIP。不要在压缩包中直接启动，不要单独移动 EXE。
3. 双击 `CourseCompiler.exe`。默认数据保存在 `%LOCALAPPDATA%\Course Compiler`，与程序文件夹分离。
4. 在「模型与设置」填写 API 地址、模型名与 API Key，再测试连接。

共用模型需要支持图片与文字输入，服务应支持返回提示词要求的 JSON。纯文本模型只能用于高级设置里的翻译或助手环节。

## 轻量版如何处理 PPT

任选一种方式：

- 安装 [LibreOffice](https://www.libreoffice.org/download/download-libreoffice/)，然后重新启动应用。
- 下载同版本 Office 组件 ZIP，将里面的 `CourseCompiler` 文件夹与轻量版同名文件夹合并。确认 `CourseCompiler\_internal\office\program\soffice.exe` 存在。

完整版已包含该组件。应用没有在线自动下载组件的功能；它不会在后台安装软件。

## 编译与复核

新建课程，添加讲义，确认顺序，再启动编译。先用几页自有材料检查模型效果与费用，再处理整门课程。每次任务可以配置请求次数上限；失败、暂停后可以继续处理，已完成的页面优先复用缓存。

进入课程后，用正文旁的复核入口对照原页修正。原始识别文本与修改历史保留。新材料可从课程库的「添加材料」入口导入，先预览、调整插入位置，再确认编译。

## 提问、笔记与导出

右侧切换至 AI 助手，选中正文，再输入问题。助手按需检索讲义；开启联网前需配置搜索服务。等待时会显示处理状态，可点击停止；已经发出的请求仍可能被服务商计费。

笔记在右栏直接编辑。课程 ZIP 是静态学习网站，解压后打开 `index.html` 即可阅读。应用内学习记录与导出 HTML 的浏览器记录属于不同存储位置，不会自动互相同步；使用备份/导出功能迁移。

## 更新、备份、卸载

更新前关闭应用，备份 `%LOCALAPPDATA%\Course Compiler`，再将新版解压到新文件夹启动。数据目录不会因为替换程序而删除。请勿同时启动源码版和发行版访问同一数据目录。

迁移到其他 Windows 账户或电脑时，可复制课程和学习记录，但需要重新配置密钥；DPAPI 加密密钥不能直接跨账户使用。

卸载可删除程序文件夹。只有你主动删除数据目录时，才会移除课程、笔记和设置。

## 排查问题

| 现象 | 处理 |
| --- | --- |
| 窗口未出现，但浏览器打开了 | 使用浏览器界面即可；如需内嵌窗口，检查系统 WebView2 Runtime |
| Windows 显示未知发布者 | 当前包没有代码签名；核对 GitHub 来源与 SHA256，自行判断是否运行 |
| PPT 无法转换 | 检查完整组件是否解压齐全，或本机 LibreOffice 是否可用 |
| 401 / 403 / 余额不足 | 检查对应 API 服务的密钥、权限和额度 |
| 模型返回格式错误 | 确认解析模型支持图片输入；换模型后先用短文档测试 |
| 启动失败 | 查看数据目录中的 `startup-error.json`，提交问题前移除私人信息 |

下载后可在 PowerShell 使用 `Get-FileHash .\CourseCompiler-Windows-x64.zip -Algorithm SHA256`，与同版本 `SHA256SUMS.txt` 对照。
