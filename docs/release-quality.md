## 本轮修复的发行问题

第一次 Windows 成品检查发现构建环境缺少 ONNX Runtime。补齐锁定依赖、重新构建并通过成品推理验证；构建脚本增加运行依赖前置检查，避免生成缺少版面运行时的包。

## 边界

测试服务为模拟响应，不产生真实模型费用，也不代表所有云端供应商可用或识别精度一致。复杂扫描件、公式、图表和表格仍需对照原页复核。清洗仅建议有可靠位置的重复边缘标注，隐藏可恢复。

未覆盖所有硬件、所有讲义、全新 Windows 虚拟机或杀毒软件组合。Windows 未 Authenticode 签名；Mac 仅 ad-hoc 签名，未 Developer ID 签名及公证。检查通过不构成零缺陷或安全认证。
