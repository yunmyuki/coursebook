## 准确性与覆盖范围

此前对 27 页真实材料进行了本地布局和路由审计，300 个区域中 268 个复用文字层、32 个计划 OCR；这不是 27 页全量云端准确率评测。另验证了三个代表页面：三栏问题、柱状图、双栏表格。两个真实区域 OCR 成功响应共输入 1,672、输出 207 tokens；更详细的限制见 [技术调研](hybrid-parsing-2026-09-30.md)。

纯扫描、多层列表、跨页表格和特殊图示仍需更多真实样本。自动测试使用模拟服务检查工作流，不代表所有模型服务实际可用或达到同等精度。示例课程采用自制原文和人工固定译文。

尚未覆盖全新 Windows 虚拟机、所有硬件与杀毒软件、Windows ARM 或其他平台；当前二进制未代码签名。上述结果不构成零缺陷或安全认证。
