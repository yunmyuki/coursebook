## 验证边界

- 这是本机成品验证，尚未覆盖全新 Windows 虚拟机、不同显卡/字体环境、所有杀毒软件、Windows ARM 或其他操作系统。
- AI 和搜索回归使用模拟服务响应，检查工作流、接口格式、引用和错误处理；不是所有服务商的真实额度调用或准确率评测。
- 自制示例包含人工固定译文，证明阅读和导出流程，不用于宣传模型效果。
- 当前二进制未做 Authenticode 代码签名；不能把上述检查描述成零缺陷或安全认证。
- 复杂扫描件、公式、密集表格和图表仍应复核。远程服务费用及可用性由用户所选提供商决定。
