# 隐私与数据流

本应用没有云端账户、远程数据库或遥测功能。桌面应用在回环地址 `127.0.0.1` 上运行本地服务；读写接口检查 Host / Origin，修改请求要求当前会话 token。它是个人本地应用，不适合作为公网或多用户服务部署。

| 数据 | 保存与流向 |
| --- | --- |
| 原始讲义、页图、编译结果 | 本地 `input/`、`courses/`、`cache/` |
| 笔记、高亮、书签、进度 | 应用模式保存到 `notes/`；静态 HTML 模式保存到浏览器 |
| 助手对话 | 本地 `assistant/`；提问时相关历史和选段发送给配置的模型 |
| API Key | 本地 `settings.json` 中加密保存；Windows 使用 DPAPI，macOS 使用钥匙串中的主密钥加密；使用时解密并发送给对应服务 |
| 页图、文字和术语 | 按编译环节发送给配置的模型服务 |
| 联网搜索词 | 仅在启用联网并执行搜索时发送给所选搜索服务 |

系统安全存储保护保存的密钥，不对整份课程或笔记做磁盘加密。能访问你的系统账户、磁盘或已登录会话的其他程序仍可能接触数据。服务商如何保留输入取决于其隐私政策。macOS 的默认数据目录为 `~/Library/Application Support/Coursebook`。

静态导出不包含 API Key、应用设置、用户笔记或助手对话，但**包含课程正文、原文件和页图**。个人记录通过独立备份导出。课程资料的分享权限由用户自行确认。

源码及发行包使用明确的文件清单组装，不包含开发者的 `.env`、`.env.local`、课程缓存、讲义、个人笔记和历史对话。演示截图使用自制示例。
