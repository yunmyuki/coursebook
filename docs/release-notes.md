# coursebook 2.0.0

面向 Windows x64 的首次公开版本。

## 提供的功能

- PDF / PPTX / PPT 讲义编译，可靠文本直接提取，复杂页面单次视觉解析。
- 原文与译文按内容单元对应，保留原页来源、图表、公式、表格与讲者备注。
- 双语左右 / 上下对照、字体选择、目录、搜索、进度、高亮、书签与右栏笔记。
- 对照原页复核，保留识别记录与修改历史。
- 根据课程主题确定翻译风格；增补材料前确认插入位置。
- 按需 AI 助手，支持选段上下文、讲义搜索、连续追问和可选联网。
- 博查、百度千帆、Tavily、Exa、Brave、SerpApi 搜索适配。
- 明确的助手等待状态、可停止请求、紧凑输入区和不打断阅读的回答定位。
- 本地加密密钥、独立模型配置、请求次数上限、缓存恢复、静态网站导出。

## 安装包选择

完整版开箱处理 PDF / PPTX / PPT。轻量版不携带 Office 转换组件，适合 PDF 用户或已经安装 LibreOffice 的用户；可合并解压 Office 组件包获得 PPT 转换能力。所有版本均需要用户自行配置 AI API。

从 [Release 附件](https://github.com/yunmyuki/coursebook/releases/tag/v2.0.0) 下载；校验值见同一发布页的 `SHA256SUMS.txt`。完整质量记录见 [质量检查](release-quality.md)。

## 已知限制

- 尚未代码签名，未提供安装向导和自动更新。
- 复杂扫描件、公式、图表和表格仍需复核；不承诺完全自动、零遗漏。
- AI 与搜索连接可能因网络、权限、服务商限流或格式差异失败。
- 在线助手需要运行本地应用；导出 HTML 支持离线阅读，但不能单独调用助手。
- 仅验证 Windows x64；其他系统与体系结构没有发行包。
- 课程与笔记没有跨设备自动同步，迁移账户后需重填密钥。

本版本未附带任何用户讲义、个人记录或 API Key。
